## 3. 📊 Data Science (DS) Series

Notes, mathematical foundations, Python tools, and methodologies for extracting actionable insights from data.

| No. | Topic Name                                                              | Description                                                                                                                                                                                                                    |
| :-- | :---------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | [Introduction to Data Science](DS/1_Introduction_to_Data_Science.ipynb) | Covers the foundations of Data Science, including Probability and Statistics, Linear Algebra, Computer Science, Machine Learning, the Data Science process, architecture, and project life cycle.                              |
| 2   | [Python for Data Science](DS/2_Python_for_Data_Science.ipynb)           | Covers NumPy, Pandas, Matplotlib, and Scikit-learn, including data manipulation, visualization, preprocessing, train-test split, linear regression, and model evaluation.                                                      |

| 5   | [Statistics using Python](DS/5_Statistics_using_Python.ipynb)           | Covers descriptive and inferential statistics, measures of central tendency and dispersion, measures of shape, sampling, sample size determination, sampling techniques, parameter estimation, MLE, and unbiased estimation.   |
